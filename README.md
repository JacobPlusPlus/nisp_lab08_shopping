# nisp_08_shopping

Projekt webowy stworzony w ramach laboratorium NISP.

## Technologie

- HTML5
- CSS3 (zmienne CSS, Flexbox, Grid, animacje)
- JavaScript (ES6+, DOM API)
- Fonty Google: Syne + DM Sans

## Struktura projektu

```
nisp_08_shopping/
├── index.html   # Główny plik HTML
├── style.css    # Arkusz stylów
├── app.js       # Logika JavaScript
├── .gitignore
└── README.md
```

## Funkcjonalności

- Przeglądanie produktów
- Dodawanie produktów do koszyka
- Zmiana ilości i usuwanie pozycji z koszyka
- Podsumowanie zamówienia

## Uruchomienie

Otwórz plik `index.html` w przeglądarce lub użyj rozszerzenia **Live Server** w VS Code.
